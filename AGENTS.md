# AGENTS.md — muse-flow

Muse entry point. This repo runs the Compact Agentic Skills Framework.

## Always-on contract

- Think before coding. State assumptions. Ask when uncertain.
- Simplicity first. Minimum code. No speculative features.
- Surgical changes. Touch only what the request requires.
- Goal-driven execution. Define verifiable success. Loop until verified.

## Router

Load `.agents/skills/using-compact/SKILL.md` at session start and after compaction. It maps intent to exactly one phase skill.

## Gates

- No code without a signed spec from `clarify`.
- No implementation without a plan from `plan-small`.
- No merge without review evidence.
- No done without verification output.
