# Clarify

Do not write code in this phase.

## Steps

1. Ask what the requester is really trying to do.
2. Surface assumptions explicitly. Ask when uncertain.
3. Present options when multiple interpretations exist.
4. Write a short spec chunk the requester can read in one pass.

## Output

A signed scope: problem, non-goals, acceptance checks. Code starts only after sign-off.
