# Plan Small

Build a plan the requester can review in one pass.

## Steps

1. Split scope into tasks sized at 2 to 5 minutes each.
2. Give each task its own verification check.
3. Mark dependencies between tasks.
4. Keep the plan free of implementation detail.

## Output

A numbered task list with checks. Implementation starts only after approval.
