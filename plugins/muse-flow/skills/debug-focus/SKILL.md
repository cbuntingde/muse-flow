# Debug Focus

Do not propose fixes before tracing cause.

## Steps

1. Reproduce with exact steps and output.
2. Isolate the failing layer.
3. Name the root cause with evidence.
4. Propose one minimal fix.

## Output

Root cause plus one fix. No speculative changes.
